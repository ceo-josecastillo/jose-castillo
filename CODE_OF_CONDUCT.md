# Código de Conducta / Code of Conduct

## Nuestro compromiso / Our Pledge

En este proyecto nos comprometemos a mantener un entorno abierto, acogedor y respetuoso para todas las personas, sin distinción de edad, género, identidad, orientación, discapacidad, apariencia, etnia, religión o nivel de experiencia.

In this project we commit to keeping an open, welcoming and respectful environment for everyone, regardless of age, gender, identity, orientation, disability, appearance, ethnicity, religion or experience level.

## Nuestras normas / Our Standards

Comportamientos que contribuyen a un ambiente positivo / Examples of behavior that contributes to a positive environment:

- Usar lenguaje amable e inclusivo / Using welcoming and inclusive language
- Respetar puntos de vista y experiencias diferentes / Respecting differing viewpoints and experiences
- Aceptar críticas constructivas con respeto / Gracefully accepting constructive criticism
- Enfocarse en lo mejor para la comunidad / Focusing on what is best for the community
- Mostrar empatía con otros miembros / Showing empathy towards other community members

Comportamientos inaceptables / Examples of unacceptable behavior:

- Lenguaje o imágenes sexualizadas y atención sexual no deseada / Sexualized language or imagery and unwelcome sexual attention
- Comentarios insultantes, despectivos o ataques personales / Insulting/derogatory comments and personal attacks
- Acoso público o privado / Public or private harassment
- Publicar información privada de otros sin permiso / Publishing others' private information without permission
- Cualquier conducta inapropiada en un entorno profesional / Other conduct inappropriate in a professional setting

## Aplicación / Enforcement

Si presencias o sufres un comportamiento inaceptable, repórtalo abriendo un *issue* en este repositorio o escribiendo a **info@globaltrackexpress.com**. Todas las denuncias se revisarán y se responderá de forma justa y confidencial.

If you witness or experience unacceptable behavior, report it by opening an *issue* in this repository or writing to **info@globaltrackexpress.com**. All reports will be reviewed and handled fairly and confidentially.

## Alcance / Scope

Este código de conducta aplica en todos los espacios del proyecto (repositorio, issues, pull requests y eventos relacionados).

This Code of Conduct applies in all project spaces (repository, issues, pull requests and related events).
