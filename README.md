## 📋 Descripción

Página web personal de **José Castillo** con diseño moderno de cristal acrílico, animaciones vivas e interactivas, asistente virtual integrado, sistema de agenda para reservar reuniones y sección de donativos. Disponible en español e inglés.

## ✨ Características

- 🎨 **Diseño acrílico premium** — tarjetas de cristal con reflejos y movimiento
- 🤖 **Asistente virtual** — chatbot local con respuestas rápidas
- 📅 **Agenda interactiva** — calendario mensual, horarios disponibles y confirmación por WhatsApp
- 🌍 **Bilingüe** — español e inglés con conmutador instantáneo
- 📱 **Responsive** — adaptado a móvil, tablet y escritorio
- ✨ **Animaciones vivas** — partículas, revelado al desplazar, efectos de brillo
- 💬 **Contacto directo** — WhatsApp, YouTube e Instagram
- ☕ **Donativos** — Buy Me a Coffee, GitHub Sponsors y criptomonedas

## 🚀 Instalación y uso

No requiere instalación ni dependencias. Es un sitio estático de un solo archivo.

```bash
# Clonar el repositorio
git clone https://github.com/ceo-josecastillo/jose-castillo.git

# Entrar al directorio
cd jose-castillo

# Abrir en el navegador
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

O simplemente visita la versión publicada:

🌐 **https://ceo-josecastillo.github.io/jose-castillo/**
