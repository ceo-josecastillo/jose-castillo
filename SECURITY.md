# Política de Seguridad / Security Policy

## Versiones soportadas / Supported Versions

Este es un sitio web estático. La versión publicada en la rama `main` es la única soportada.

This is a static website. The version published on the `main` branch is the only supported one.

| Versión / Version | Soportada / Supported |
| ----------------- | --------------------- |
| `main` (actual)   | ✅                    |
| Ramas antiguas / Old branches | ❌           |

## Reportar una vulnerabilidad / Reporting a Vulnerability

Si encuentras una vulnerabilidad de seguridad en este sitio, por favor repórtala de forma responsable:

If you find a security vulnerability in this site, please report it responsibly:

1. **No la publiques** en un issue público / **Do not publish it** in a public issue.
2. Escríbenos a **info@globaltrackexpress.com** con los detalles / Write to **info@globaltrackexpress.com** with the details.
3. Describe el problema, los pasos para reproducirlo y el impacto potencial / Describe the issue, steps to reproduce it, and the potential impact.

Nos comprometemos a responder en un plazo razonable y a agradecer públicamente tu colaboración (si así lo deseas).

We commit to responding within a reasonable timeframe and to publicly thank you for your collaboration (if you wish).

## Notas / Notes

- Este sitio no almacena datos de usuarios en servidores propios / This site does not store user data on its own servers.
- El formulario de contacto abre tu cliente de correo; no envía datos a terceros / The contact form opens your email client; it does not send data to third parties.
- Los enlaces de donativos llevan a plataformas externas oficiales (Buy Me a Coffee) / Donation links go to official external platforms (Buy Me a Coffee).
